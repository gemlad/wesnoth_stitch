# Archive

Superseded working documents, kept for the record. **Nothing here is maintained** — where it
disagrees with [`../design.md`](../design.md) or the code, it is wrong and the code is right.

| Doc | What it was |
| --- | --- |
| [design-v1.md](design-v1.md) | The Python-prototype-era design doc, superseded by `design.md` (v2). |
| [milestone-1-tasks.md](milestone-1-tasks.md) | M1 breakdown — Electron + Vite + React scaffold, sprite browser. |
| [milestone-2-tasks.md](milestone-2-tasks.md) | M2 breakdown — conversion pipeline: DMC mapping, colour reduction, Konva preview. |
| [milestone-3-tasks.md](milestone-3-tasks.md) | M3 breakdown — export: PNG and the printable PDF chart with floss key. |
| [milestone-4-tasks.md](milestone-4-tasks.md) | M4 breakdown — packaging, sprite download, licence, first release. |

The four milestone breakdowns were the plans for **v1**, which shipped as `v1.0.0`. They are
archived rather than deleted because they carry the *reasoning* behind decisions the code still
lives with — why sprites are downloaded rather than bundled, why the first release is Windows
and unsigned — and several are cited by name from `design.md` and from the decision records.
